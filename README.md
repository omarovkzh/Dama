# ДАМА ★ — Советские Шашки

> *«Шашки — это не просто игра. Это искусство мышления.»*

---

## Что это такое

**ДАМА** — веб-платформа для игры в русские шашки с уникальным визуальным стилем советского конструктивизма 1920-х годов и современным UX. Не просто доска — полноценный продукт с ИИ-противником и персональным тренером на базе Claude.

**Для кого:** Игроки всех уровней, которые хотят не просто сыграть, но и развиваться. Ностальгирующие по советской эстетике + современная молодёжь, которой нравится ретро-стиль.

**Почему это ценно:** Шашки незаслуженно забыты на фоне шахмат. ДАМА возвращает эту игру в стильной оболочке с умными функциями, которых нет у конкурентов.

---

## Функционал

### Игровая механика
- ✅ Полные правила русских шашек
- ✅ Обязательное взятие (с индикатором)
- ✅ Цепные взятия (несколько за один ход)
- ✅ Превращение в дамку (★)
- ✅ Ходы дамки на любое расстояние
- ✅ Определение победителя (нет фигур / нет ходов)

### Противник — ИИ (Minimax + Alpha-Beta Pruning)
- 🟡 **Новичок** — случайный выбор с приоритетом взятий
- 🟠 **Боец** — глубина поиска 4 (основной режим)
- 🔴 **Мастер** — глубина поиска 7, сложный противник

### ИИ-Тренер (Claude API)
- ⚡ Анализ последних ходов в реальном времени (кнопка в боковой панели)
- ⚡ Полный разбор партии после её завершения
- Советский тренер — строгий, конкретный, без лишних слов

### UX / UI
- 🎨 Стиль советского конструктивизма (красный + кремовый + чёрный, шрифт Bebas Neue)
- 📋 История ходов в нотации (A1-B2, A1:C3 для взятий)
- 🎯 Подсветка возможных ходов
- 🏆 Счётчик сессии (побед игрока vs ИИ)
- 📊 Статистика партии (ходов, взятий, дамок)
- 📱 Адаптивный дизайн (телефон / планшет / десктоп)
- 📜 Встроенные правила игры

## Стек

- Чистый HTML / CSS / Vanilla JavaScript (без фреймворков — быстро и везде работает)
- Claude API (`claude-sonnet-4-20250514`) — ИИ-тренер
- Алгоритм: Minimax с Alpha-Beta Pruning для сильного ИИ-противника
